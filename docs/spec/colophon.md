# 奥付の著者紹介・正誤表リンク・著作権表記 要求・要件

奥付ページへ著者紹介・正誤表リンク・著作権表記を，
書籍ごとのデータから自動で流し込む仕組みの要求・要件を定める．

## 背景と要求（why）

- 奥付の著者紹介・正誤表リンクを毎回手書きすると，
  書籍間で体裁がばらつき，記載漏れや更新漏れが起きる．
- データと体裁を分離する．データは書籍ごとの `config/book.yaml` に置き，
  体裁はテンプレート（マーカー配置）とテーマ CSS が担う．
  これによりテンプレート更新を全書籍へ一律に波及させられる．
- 正誤表は公開サイトで管理している（`docs/spec/edition-errata.md`）．
  書籍本体の奥付から，読者をその入口へ案内する．

## 用語集（ユビキタス言語）

表 1. 奥付流し込みで使う用語

| 用語 | 意味 |
|---|---|
| マーカー | `99-colophon.md` に単独段落として書く置換目印．本仕様が扱うのは `{{authors}}`・`{{errata}}`・`{{copyright}}` の 3 つ．`{{isdn}}` は `docs/spec/isdn.md` が扱う |
| 著者紹介（authors） | 氏名・SNS ID・紹介文・リンク 1 つからなる著者データの一覧 |
| 正誤表リンク（errata.url） | 公開正誤表サイトの当該書籍ページを指す URL |
| 著作権表記（copyright） | © 表記（年・権利者名）と無断複製・転載の禁止文言．`config/book.yaml` の `copyright` 節から流し込む |

## 要件（what）

- ビルド時に `{{authors}}`・`{{errata}}`・`{{copyright}}` マーカーを
  置き換える．置き換え処理は `config/book.yaml` のデータを使い
  `scripts/inject-colophon.mjs` が担う．
- 著者紹介は次の項目を持つ．複数著者に対応する．
  - 氏名（`name`）: 必須．
  - SNS ID（`sns`）: 任意．氏名の後ろに「（ID）」の形で表示する．
  - 紹介文（`bio`）: 任意．140 文字程度を目安にする（機械検査はしない）．
  - リンク（`link`）: 任意．`title` と `url` を 1 組だけ持つ．
- 正誤表リンクは http(s) の URL を 1 つ持つ．
- 配置は著者紹介がページ上部，それ以外は下部寄せの 1 ブロックとする．
  下部ブロックは書籍タイトル・発行履歴・奥付情報・正誤表リンク・
  ISDN 番号・著作権表記の順に並べる．ISDN 番号は `docs/spec/isdn.md`
  が扱う．体裁の詳細はテーマ CSS（`.colophon-*`）に委ねる．
- 発行履歴は書籍タイトルの直下に「YYYY年MM月DD日 第N版第N刷発行」の
  形式で書く．第 1 版は「初版」と表記してよい．
  版・刷が増えるたびに段落を 1 行ずつ追記する．
  原稿へ手書きするデータであり，マーカーによる流し込みは行わない．
- 著作権表記は `config/book.yaml` の `copyright` 節から流し込む．
  年（`year`，必須）・権利者名（`holder`，任意）・
  禁止文言（`notice`，任意）を持つ．
  `holder` を省略した場合は `book.yaml` の `author`（表紙の名義）を使う．
  `notice` を省略した場合は既定の禁止文言を使う．
  `year` は 4 桁の数値，または `"YYYY-YYYY"` 形式の文字列とする．
- 著作権表記の出力は 2 段落とする．
  1 段落目は「© {year} {holder}」，2 段落目は禁止文言とする．
- データが無い・不正な場合，マーカーを出力から取り除き，
  ビルドログへ警告を出す．出版物へマーカー文字列を残さない．
  `{{copyright}}` の `year` が上記形式に反する場合も同様に扱う．
- `errata.url` が `errata/errata.yml` の slug を含まない場合，
  `npm run check:errata` が警告する（別書籍ページへの誤リンク防止）．

受け入れ条件は次のとおり．

- サンプルデータのビルドで，奥付に著者紹介と正誤表 URL が表示される．
- `authors`・`errata` を消してビルドしても，マーカー文字列が PDF に残らない．
  あわせてビルドログに警告が出る．
- サンプルデータのビルドで，奥付最下部に著作権表記が表示される．
- `copyright` を消してビルドしても，マーカー文字列が PDF に残らない．
  あわせてビルドログに警告が出る．
- `npm test` が全件通る．

## スコープ外

- 著者写真・アイコン画像の掲載．
- 1 著者あたり複数リンク（SNS 一覧など）の掲載．リンクは 1 つに限る．
- 奥付以外のページ（あとがき等）への著者紹介の流し込み．
- 発行履歴の自動生成（`errata/errata.yml` の editions からの導出）．
  editions は刷を管理しておらず，公開サイト連携のスキーマへ刷を足すと
  収集側へ影響が及ぶため，発行履歴は手書きとする．
  Issue #63 はこの流し込みを提案したが，本方針を再確認し不採用とした．
- 「All Rights Reserved」等，付加句の既定出力．
  必要な書籍は `copyright.notice` で個別に対応する．
