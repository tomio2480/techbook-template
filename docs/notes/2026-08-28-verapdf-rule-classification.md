# veraPDF 失敗ルールの分類と上流報告の要否

Issue #197・#198 の対応後も残る veraPDF（PDF/UA-1）の失敗を分類する．
残る 5 ルールの帰属（テンプレ側・上流由来・意図した非宣言）と根拠を記す．
上流の既知 Issue の確認結果と，報告見送りの判断も記録する（Issue #199）．

## 分類の全体像

PR #200（#197）と PR #201（#198）のマージ後，
CI の検証レポート（run 33128813282）は
失敗 5 ルール・759 チェックを報告する．分類を表 1 に示す．

表 1. veraPDF 失敗ルールの帰属

| 条項 | 失敗数 | 内容 | 帰属 |
|---|---|---|---|
| 7.3-1 | 0（解消） | Figure タグの代替テキスト欠落 | テンプレ側．#197 で解消 |
| 7.1-8 | 0（解消） | Catalog の Metadata 鍵欠落 | テンプレ側．#198 で解消 |
| 5-1 | 1 | PDF/UA 版数宣言の欠落 | 意図した非宣言 |
| 7.1-3 | 349 | Artifact でも実コンテンツでもない内容 | 上流由来 |
| 7.18.5-2 | 176 | リンク注釈の Contents（代替説明）欠落 | 上流由来 |
| 7.18.1-2 | 176 | 注釈が構造ツリーへ未接続 | 上流由来 |
| 7.2-20 | 57 | LI 直下に Lbl・LBody 以外の要素 | 上流由来 |

## テンプレ側で解消した 2 ルール

- 7.3-1 は `figure` ラッパーと表紙の装飾画像が原因だった．
  rehype 前処理（`scripts/label-figures.mjs`）で解消した（#197）．
- 7.1-8 は XMP メタデータの埋め込みで解消した（#198）．
  `scripts/add-pdf-metadata.mjs` がビルドの最終段で書き込む．

## 意図した非宣言の 1 ルール

条項 5-1 は「pdfuaid:part による版数宣言が無い」という指摘である．
上流由来の非準拠が残る現状で宣言すると，事実と異なる適合表明になる．
このため書かない判断とした（#198）．判断は
[タグ付き PDF 生成 spec](../spec/pdf-tagging.md) が明記する．
上流由来の 4 ルールが解消したときに宣言を再検討する．

## 上流由来の 4 ルール

4 ルールはいずれも原稿・テンプレの HTML では制御できない．
タグ付けは Vivliostyle CLI 内部の Chromium（print-to-PDF）が行い，
その変換の限界に由来するためである．

### 7.1-3: 未マークの内容（349 件）

構造ツリーから外れた内容を，Chromium が Artifact として刻まず
未マークのまま残す．最小構成の実験で機序を確認した．
`role="presentation"` の画像は構造ツリーから消えるが，
描画内容は Artifact にならず本ルールの違反として数えられる．

全 349 件の正体は特定していない．レポートの checks 記録は
先頭 100 件のサンプル（veraPDF の表示上限）であり，
1〜19 ページに分布する．表紙の装飾画像 7 件は実験の結果と一致する．
必要になったら最小構成で切り分ける．

### 7.18.5-2・7.18.1-2: リンク注釈（各 176 件）

リンク注釈に `/Contents`（代替説明）が無く，構造ツリーの Link
要素へも接続されていない．件数が一致するため同じ注釈群である．
目次・索引・本文の URL リンクが該当する．
Chromium のタグ付けがこれらを生成しないことに由来する．

### 7.2-20: リスト構造（57 件）

LI 構造要素の直下に Lbl・LBody 以外の要素が置かれる．
Chromium のリストのタグ付けに由来する．

## 件数は環境で揺れる

7.1-3 の件数は同じ原稿でも実行環境で揺れる（324〜349 件を観測）．
チェック総数も local と CI で一致しない（738〜759 件）．
レンダラ（Chromium）の版差によるとみられる．
件数の増減を追うときは同一環境の前後で比べること．
veraPDF の JSON 構造を実出力から採った経緯は
[2026-08-27 のノート](2026-08-27-verapdf-ci-report.md) を参照．

## 上流の既知 Issue と報告要否

確認した既知 Issue は次のとおり．

- [vivliostyle.js#1555](https://github.com/vivliostyle/vivliostyle.js/issues/1555)（クローズ済み）．
  Adobe Reader の読み上げが失敗する報告．
- [vivliostyle.js#1561](https://github.com/vivliostyle/vivliostyle.js/issues/1561)（オープン）．
  ページマージンボックス（柱・ノンブル）へ
  `aria-hidden` を付けるかの議論．ヘッダ・フッタの Artifact 化に
  対応する論点であり，7.1-3 と地続きである．
- [vivliostyle-cli#539](https://github.com/vivliostyle/vivliostyle-cli/issues/539)（クローズ済み）．
  タグ付き PDF が出ない報告．v8.16.1 で修正済み．
- リンク注釈（7.18.x）とリスト構造（7.2-20）を個別に扱う Issue は，
  両リポジトリに見当たらなかった．

報告は当面見送る．根拠は次のとおり．

- 4 ルールの機序は Vivliostyle のコードでなく，Chromium の
  print-to-PDF タグ付けにある．Vivliostyle への起票は解決経路に
  ならず，Chromium 側の改善を待つ構図になる．
- マージンボックスの扱いは #1561 が既に議論中で，重複起票になる．

再検討のトリガは次の 2 つとする．

- Chromium のタグ付き PDF 生成が改善したとき．Artifact の出力と
  Link 要素への注釈接続が対象である．
- #1561 が動き，マージンボックスの扱いが決まったとき．
