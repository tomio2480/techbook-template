## 背景

- 同人誌の作品識別子 ISDN の申請情報保管と，発行された番号・
  バーコードの誌面反映をテンプレートへ組み込んだ．
- 申請はユーザーが手動で行い，テンプレートは保管と反映だけを担う．

## 判断

- 申請情報は `config/book.yaml` へ統合せず `config/isdn.yaml` を新設した．
  組版に使わない申請専用項目（よみがな・レーティング等）の混入を避けた．
- 奥付の番号は正誤表リンク下・コピーライト直上の単独段落とした．
  商業書籍の ISBN 表記の慣例へ近づけた．
- バーコードの配置は書籍 JAN コードの慣行（表 4 左上）へ準拠した．
  isdn.jp を確認した範囲では公式の配置規定が見当たらないためである．
  数値（天 10mm・左 12mm・幅 40mm）は当方の既定値であり，
  テーマ CSS の変数（`--isdn-barcode-*`）で調整できる形にした．
- 番号が無効でもバーコード画像があれば裏表紙へ配置する仕様とした．
  画像は運営からの受領物であり，画像自体を正とみなすためである．
- 番号検査は 13 桁・プレフィックス 278/279・チェックディジット（モジュラス
  10 ウェイト 3・1．EAN-13 と同方式）を機械検査にした．
  仕様は isdn.jp の about ページで確認した．

## 代替案と棄却理由

- `book.yaml` への `isdn` 節追加は，設定ファイル数を増やさない利点より
  申請専用項目の混入の欠点が大きいと判断して棄却した．
- 裏表紙のデザインテンプレート化は本対応から外し Issue #58 へ分離した．
  バーコード配置の受け皿となる最小ページのみ先行させた．
- マーカー置換の共通化（`inject-colophon.mjs` との helper 共有）は
  見送り，`inject-isdn.mjs` に同方式の実装を複製した．
  プラグインごとの自己完結を優先し，重複は約 25 行に留まる．

## 詰まった箇所と学び

- 目次マージ（`add-line-numbers.mjs`）の除外指定は `href="` への
  前方一致であり，既存の `cover\.html` 指定は `back-cover.html` に
  掛からなかった．目次へ誤ラベル（フォールバックのプロジェクト名）の
  項目が混入し，実ビルドで初めて発覚した．
  単体テストだけでは検出できず，フルビルドでの受け入れ確認が効いた．
  除外一覧は配列定数（`TOC_EXCLUDED_HREF_PATTERNS`）へ集約した．
- CodeQL の CI 失敗（cancelled）は「hosted runner がジョブを取得
  できない」一時要因だった．`gh run view <id>` の ANNOTATIONS に
  原因が出る．コード起因と決めつけず，まず注記を確認するとよい．
- `gh pr merge --delete-branch` は複数ワークツリー構成で失敗する．
  マージ後にローカル `main` へ切り替えようとし，`main` が別
  ワークツリーでチェックアウト済みだと止まる．マージ自体は成功して
  おり，リモートブランチ削除だけ `git push origin --delete` で補う．
- ISDN 番号の記入例は桁数を機械検査と突合してから書く．
  当初の例は 12 桁相当で 13 桁検証と矛盾し，レビューで指摘を受けた．
