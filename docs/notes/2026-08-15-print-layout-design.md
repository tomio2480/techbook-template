# 紙入稿用 PDF の面付けと小口のつめ

紙入稿用 PDF（`npm run build:print`）を実装した際の判断と，
Vivliostyle の挙動でつまずいた点を記録する．
要求・要件は `docs/spec/print-layout.md` を参照．

## 背景

電子書籍用の PDF はそのまま配布できる状態にあったが，紙で入稿するには
ページの並びを製本の都合へ合わせる必要があった．
求められたのは次の 3 つである．

- 区分の始まりを指定した面から始める（改丁）．
- 総ページ数を綴じの単位の倍数へ揃える（面付け）．
- 章の位置を小口から見分けられるようにする（つめ）．

## 判断

### 白ページを作らず，MEMO ページを実体として差し込む

Vivliostyle は改ページで生じた白ページへ何も描画しない．
枠・背景・ページ余白ボックスのいずれも出ず，`@page :blank` も効かない．
最小構成で試したところ，`:blank` の指定は白ページではなく次のページへ
適用された（`@vivliostyle/core` 2.39.0 で確認）．

そこで白紙を後から飾る方針を捨て，必要な位置へ MEMO ページを差し込む形にした．
差し込む位置と枚数を決めるには各区分のページ数が要るため，ビルドを 3 パスにした．

1. 組版パス: Markdown から HTML を生成する．
2. 測定パス: 改丁を外して組み，各区分のページ数を実測する．
3. 本番パス: 実測値から MEMO ページの位置と枚数を決めて組み直す．

最後に，実測から求めた想定ページ数と組み上がりを突き合わせて検査する．
食い違えばビルドを失敗させ，誤った入稿データが出ないようにした．

### 面の指定は `config/book.yaml` を単一の出所にする

当初はテーマ CSS 側にも区分ごとの改丁指定を置き，安全網とした．
しかしレビューで指摘を受けた．`chapter_start: verso` にすると，
電子書籍用テーマの `break-before: right` が残って必ずビルドが失敗する．

指定が 2 箇所にある構造そのものが原因なので，`book.yaml` へ寄せた．
ビルドが指定を読み，対象の生成 HTML へ `print-side-recto` /
`print-side-verso` を付ける．テーマ CSS は付いたクラスを面へ翻訳するだけとし，
区分の一覧を持たせない．

### つめの文字はページ余白へ流し込む

つめへ章番号と章タイトルを刷るため，`position: running()` を使った．
ページ背景では文字を置けないためである．
流し込みから外れるため，ページ数の計算には影響しない．

## 代替案と棄却理由

- **PDF を後処理して白ページへ描画する**: `pdf-lib` などの依存追加が要る．
  体裁が CSS から JavaScript へ移り，余白の値を二重に持つ．
  この重複を避けるため採らなかった．
- **MEMO ページの位置を CSS だけで決める**: 白ページを装飾できない以上，
  実現できない．
- **章ごとの位置指定 CSS を静的に書き並べる**: 章数の上限が生まれる．
  章数から割合を計算して生成する形にし，上限をなくした．

## つまずいた点

- **余白 0 のページではページ余白ボックスが出ない**．
  測定パスの目印を `@page :nth(1)` の余白ボックスへ置いたところ，
  余白 0 で組む裏表紙だけ目印が出なかった．
  測定パスに限り上余白を戻して回避した．ページ数は変わらない．
- **`vivliostyle build --style` は全ドキュメントへ追加スタイルを重ねられる**．
  2 パス目は生成済み HTML を入力にするため，`theme` の差し替えでは
  紙用スタイルが届かない．`--style` なら入力の種類を問わず適用される．
- **PDF のページ数はページツリーの `/Count` を正とする**．
  ページ定義は平文と圧縮されたオブジェクトストリームの双方に現れ，混在もする．
  数え上げでは二重計上と数え落としの両方が起きた．
- **textlint の文長は折り返しを結合した文で判定される**．
  行単位の自己点検では漏れる．段落として結合してから数える必要がある．

## 検証の手段

ブラウザで PDF を目視できない場合でも，`@opendataloader/pdf` の JSON 出力から
要素の外接矩形を取り出せる．つめの寸法・位置・文字色を数値で裏取りできた．
ページ単位のテキスト抽出には `--text-page-separator` を使う．
`--include-header-footer` を併せると，柱やノンブルまで拾える．
